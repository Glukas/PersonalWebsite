2. Zweck der Website

Diese Website ist mein persönliches Portfolio und dient der Darstellung meines Lebenslaufs sowie einer Auswahl eigener Projekte, darunter mehrere kleine Web-Tools (z. B. 2FA Generator, QR-Code Generator, Passwort-Generator, WordMixer und die Krypto-Tool). Sie wird privat und nicht kommerziell betrieben.

3. Server-Logfiles

Diese Website wird über GitHub Pages bereitgestellt. Beim Aufruf der Website können aus technischen Gründen Daten (z. B. IP-Adresse, Datum und Uhrzeit des Zugriffs, aufgerufene Seite sowie Informationen zum verwendeten Browser) durch GitHub verarbeitet und in Server-Logdateien gespeichert werden. Diese Verarbeitung erfolgt durch GitHub und dient unter anderem der Bereitstellung, Sicherheit und Stabilität des Dienstes. Ich selbst habe keinen Zugriff auf diese Server-Logdaten und führe keine Zusammenführung mit anderen Datenquellen durch. Weitere Informationen zur Datenverarbeitung durch GitHub finden Sie in der Datenschutzerklärung von GitHub: GitHub Datenschutzerklärung

4. Eingebundene externe Dienste

Für Design und Funktion bindet diese Website folgende externe Dienste ein:

  • Tailwind CSS (cdn.tailwindcss.com) für das Styling der Elemente.
  • Simple Icons (cdn.simpleicons.org) für die Technologie-Icons.
  • jsSHA (cdnjs.cloudflare.com) für die HMAC-SHA1 Berechnung im 2FA Generator.
  • QRCode.js (cdn.jsdelivr.net) zur Erstellung von QR-Codes.
  • jsPDF (cdnjs.cloudflare.com) für den PDF-Export des QR-Code Generators.
  • Chart.js (cdn.jsdelivr.net) für die Kursverlauf-Grafiken im Crypto Dashboard.
  • Die Website verwendet keine externen Schriftarten sondern nur System-Schriftarten wie Arial, Segoe UI und system-ui.

Beim Laden dieser Dienste kann der Browser des Besuchers automatisch die IP-Adresse an den jeweiligen Anbieter übermitteln. Dies liegt in der technischen Natur solcher Einbindungen und lässt sich nicht vollständig vermeiden.

5. Browser-Speicher und Cookies

Einige interaktive Funktionen nutzen den lokalen Browser-Speicher (z. B. localStorage) für Einstellungen wie Favoriten oder Verlauf. Diese Daten verbleiben auf dem jeweiligen Gerät und werden nicht an einen Server übermittelt. Es werden keine Cookies zu Tracking-Zwecken verwendet.

6. Meine Web-Tools (2FA, Passwort-Generator, QR-Code, To-Do, WordMixer)

Diese Tools laufen komplett lokal im Browser, ohne Datenübertragung an einen Server.

7. CoinGecko API (Crypto Dashboard)

Das Crypto Dashboard lädt aktuelle Kurs- und Marktdaten von der öffentlichen API des Anbieters CoinGecko (coingecko.com). Dabei werden keine persönlichen Daten übermittelt. Wie bei jeder externen Anfrage kann die IP-Adresse des Besuchers technisch bedingt an CoinGecko übertragen werden. Das Crypto Dashboard speichert ausserdem favorisierte Coins lokal im Browser-Speicher (localStorage) des jeweiligen Geräts; diese Daten verlassen den Browser nicht.

8. Kontaktaufnahme

Bei Kontaktaufnahme per E-Mail werden die übermittelten Angaben ausschliesslich zur Bearbeitung der Anfrage verwendet. Eine Weitergabe an Dritte erfolgt nicht.
